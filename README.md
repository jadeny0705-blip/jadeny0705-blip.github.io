# 彭艺佳个人介绍网站

这是一个不依赖框架和构建工具的响应式单页网站，可直接打开 `index.html` 预览，也可将整个目录上传到任意静态网站托管服务。

## 文件说明

- `index.html`：页面内容与结构
- `styles.css`：视觉样式、响应式布局与动效
- `script.js`：移动端导航、滚动动画、项目筛选与阅读进度
- `favicon.svg`：浏览器标签图标
- `2028届-四川大学-彭艺佳简历.doc`：网站内的简历下载文件

## 本地预览

直接双击 `index.html` 即可。如果需要对内网或手机预览，可以将整个目录交给任意静态文件服务器。

## 发布

将上述网页文件和简历文件上传至同一目录，适用于 GitHub Pages、Cloudflare Pages、Netlify、Vercel 或普通静态服务器。

## 修改内容

文字内容集中在 `index.html`；主色、字体与间距参数集中在 `styles.css` 顶部的 `:root` 中。
